# UI Design Standards

## 1. Design Philosophy

- Design interfaces for real products, not AI demonstrations.
- Every page must have a clear visual hierarchy.
- Use consistent spacing, typography and color systems.
- Choose a visual direction appropriate to the product.
- Avoid generic AI-generated design patterns.

## 2. Avoid

- Unnecessary purple and blue gradients.
- Excessive glassmorphism.
- Too many rounded cards.
- Repetitive dashboard layouts.
- Unnecessary decorative icons.
- Random animations.
- Excessive shadows.
- Fake charts and meaningless statistics.

## 3. Typography

- Establish a clear heading hierarchy.
- Use readable font sizes.
- Maintain consistent font weights.
- Avoid excessive font variations.

## 4. Layout

- Prioritize content hierarchy.
- Use consistent spacing tokens.
- Create balanced whitespace.
- Use responsive layouts.
- Avoid unnecessary nested containers.

## 5. Components

- Reuse components when appropriate.
- Keep components focused.
- Avoid oversized components.
- Use consistent button, input and table styles.

## 6. Responsive Design

- Support desktop, tablet and mobile.
- Prevent horizontal overflow.
- Ensure interactive elements are usable on touch screens.

## 7. Accessibility

- Use semantic HTML.
- Provide labels for inputs.
- Support keyboard navigation.
- Maintain sufficient color contrast.
- Provide visible focus states.

## 8. Before Completion

- Inspect the rendered interface.
- Check responsive behavior.
- Check loading, empty, error and success states.
- Verify all buttons and interactions work.
- Do not leave placeholder content in completed features.
